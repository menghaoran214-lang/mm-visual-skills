# Article Illustration QA

交付前检查：

- [ ] 是否完整读过文章，而不是只根据标题配图
- [ ] 每张机制图只服务一个认知任务
- [ ] 没有两张图重复概括同一个意思
- [ ] 图位是否对应读者最可能“卡一下”的位置
- [ ] 数据、分类、参数是否被误画成机制图
- [ ] 真实证据是否优先建议使用真实截图
- [ ] 纯观点、转场和 CTA 是否避免硬塞配图
- [ ] 生成图是否均为独立图片，而非拼图
- [ ] 图片比例是否服务内容，而非机械统一
- [ ] 中文标签是否足够短，降低乱码风险
- [ ] 是否输出“其他截图 / 表格 / 证据图”建议
- [ ] 已执行目标风格 Skill 的参考素材准入检查，且实际传入样图给生图工具；失败时已阻断而非回退成其它画风
- [ ] 是否按当前具体风格 Skill 的 QA 再检查一次
