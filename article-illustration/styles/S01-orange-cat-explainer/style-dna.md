# S01 Style DNA · 橘猫机制说明书

## Core purpose

把正文里抽象、晦涩、流程化、难脑补的内容，翻译成“橘猫正在操作一个系统”的可视动作。

这不是装饰图，也不是整篇总结海报。

## Fixed IP

橘猫作为“操作员 / 解释员”：

- 橘色猫
- 黑色针织帽
- 圆形黑墨镜
- 黑色高领
- 简化、扁平、编辑说明书插画感
- 不强调写实毛发
- 不默认加入雪茄等非必要元素
- 猫必须参与解释动作，不能只在角落摆 pose

## Visual language

- 纯白或暖白背景
- 大量负空间
- 细黑线稿
- 道具尽量控制在 2–3 个核心物体
- 一张图只讲一个动作 / 机制 / 认知任务
- 优先使用简单物理隐喻：纸张、箱子、夹子、筛子、流水线、插头、机器、书、盖子、小船、路障等

## Color semantics

- **橙色**：流程、流向、输入输出
- **蓝色**：操作提示、解释、口语化批注
- **红色**：真实风险、警告

颜色必须有职责，不要互相抢戏。

## Humor

固定原则：

> 先解释清楚，再加一点冷幽默。

可用方式：

- 猫的动作有戏
- 道具有轻微反差
- 蓝色批注更像人话
- 把原文隐喻真的画出来

例如：

- “先别想太远”
- “先跑通再说”
- 猫被 Version 10.0 规划压住
- 猫从代码废料里挑核心模块
- 猫推着 MVP 小船下水

幽默永远是第二层，不能损害理解。

## Ratio

不固定。

根据内容选择 16:9、4:3、3:4 或其他合理比例。
