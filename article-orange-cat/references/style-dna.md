# Style DNA · 橘猫机制说明书

## Core purpose

把正文里抽象、晦涩、流程化、难脑补的内容，翻译成“橘猫正在操作一个系统”的可视动作。

这不是装饰图，也不是整篇总结海报，更不是彩色科普信息图。

## Fixed IP

橘猫作为“操作员 / 解释员”：

- 橘色猫
- 黑色针织帽
- 圆形黑墨镜
- 黑色高领 / 黑衣服
- 简化、扁平、编辑说明书插画感
- 不强调写实毛发
- 不默认加入雪茄等非必要元素
- 猫必须参与解释动作，不能只在角落摆 pose

## Visual language

目标观感接近“手绘编辑插画 / 机制说明书”：

- 纯白或暖白背景
- 85% 左右视觉空间保持白底与留白感
- 黑色手绘线稿是主体，不使用大面积彩色块
- 一张图通常是一个场景、一个流程或一个左右对照
- 道具尽量控制在 2–3 个核心物体
- 一张图只讲一个动作 / 机制 / 认知任务
- 优先使用简单物理隐喻：纸张、箱子、夹子、筛子、流水线、插头、机器、书、盖子、小船、路障等
- 文字以物件标签、短说明、蓝色手写批注为主
- 不做顶部大 Banner，不做卡片式仪表盘排版

## Color semantics

- **黑色**：主要线条、文字、主体结构
- **橙色**：猫本体、流程、流向、少量关键重点
- **蓝色**：手写操作提示、解释、口语化批注
- **红色**：真实风险、错误、警告
- **绿色**：仅用于“正确 / 通过 / 可行”等明确正向判断

颜色必须有职责，不要互相抢戏。

## Typography

- 文案极简
- 不用大段正文
- 不用彩色粗体海报标题
- 优先黑色手写 / 编辑说明风标签
- 蓝色批注应像人工手写备注，而不是 UI 卡片标题

## Humor

固定原则：

> 先解释清楚，再加一点冷幽默。

可用方式：

- 猫的动作有戏
- 道具有轻微反差
- 蓝色批注更像人话
- 把原文隐喻真的画出来

幽默永远是第二层，不能损害理解。

## Ratio

不固定。根据内容选择 16:9、4:3、3:4 或其他合理比例。
