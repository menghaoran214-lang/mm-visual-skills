# Negative Rules

以下任一情况出现，都视为明显风格漂移：

- 彩色天空、草地、城市、自然景观背景
- 渐变背景、大面积蓝紫色背景、大面积彩色区域
- 六宫格、九宫格、多面板拼图
- 一张图塞入多个不相关机制
- 海报式大标题占满画面
- 顶部大 Banner / 大色块标题条
- 密集多栏卡片
- 彩色 UI 卡片、Dashboard 信息图风
- 普通“儿童科普卡通”画风
- 把整篇文章压成一张总结信息图
- PPT 式结构堆叠
- 复杂背景和纯装饰场景
- 3D、写实毛发、电影光效
- 猫只站着卖萌，不参与解释
- 普通橘猫但没有黑针织帽、圆黑墨镜、黑高领
- 大段中文放在画面里
- 橙、蓝、红、绿同时大面积抢戏
- 没有真实风险却滥用红色
- 为了搞笑牺牲认知清晰度
- 连续多张图都在重复文章结论
- 每次固定套用同一个旧构图
- 无视真实截图而用假插画替代证据

## Hard fail

以下情况直接重做，不进入轻微修正：

1. 生成成“彩色信息图 / 科普海报”
2. 生成成多格拼图
3. 白底与留白明显不足
4. 固定橘猫身份丢失
5. 黑色手绘线稿不再是主要视觉语言
