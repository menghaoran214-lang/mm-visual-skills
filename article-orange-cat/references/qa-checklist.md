# QA Checklist

## 准入检查（任一失败即禁止调用生图工具）

- [ ] 三张样图均经过真实文件解码，脚本/工具检查全部通过
- [ ] 模型已实际看到样图，不只是读到路径、链接或文字规则
- [ ] 当前生图工具已实际收到样图作为参考输入，不能用纯文字替代
- [ ] 第一张风格探针与母版比对合格后，才继续后续图片

## 语义与参考图输入验收（任一失败即不交付）

- [ ] 已锁定作者真正主张、保留对象、过滤条件、禁止推论与收益状态
- [ ] 画面没有把筛选具体机会扩大为否定 AI/Crypto 等整个行业
- [ ] 未将目标/预测收益描绘为已经赚到钱
- [ ] 生图调用中明确含有实际参考图片或 MEDIA ID，而非仅文字参考
- [ ] Reference Input Confirmed 与 Visual/Semantic QA Passed 分开报告

## 画面质量

- [ ] 第一眼能否说出这张图解释什么
- [ ] 是否只有一个核心机制 / 动作
- [ ] 橘猫身份是否正确：橘猫、黑针织帽、圆黑墨镜、黑高领
- [ ] 猫是否正在参与关键动作
- [ ] 是否保持白底 / 暖白底与充足留白
- [ ] 道具是否精简到必要数量
- [ ] 橙色是否只表示流程
- [ ] 蓝色是否只表示解释 / 操作提示
- [ ] 红色是否只表示真实风险
- [ ] 是否有适量趣味但不妨碍理解
- [ ] 是否避免海报、密集信息图、整篇总结图
- [ ] 中文标签是否短、清楚、无明显乱码
- [ ] 当前比例是否真正服务构图
