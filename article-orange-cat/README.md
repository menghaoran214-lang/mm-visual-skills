# 橘猫机制说明书 · 正文配图 Skill

> 一个风格就是一个 Skill。

这是 MM Visual Skills 的正文配图风格 Skill：`$mm-article-orange-cat`。

它专门把抽象机制、流程、卡点、技术关系和项目复盘，画成“橘猫正在操作一个系统”的白底线稿说明图。

## 单独安装

```text
帮我安装这个 Skill：
https://github.com/menghaoran214-lang/mm-visual-skills/tree/main/article-orange-cat
```

安装整套 MM Visual Skills 时，本 Skill 会和其他根级 Skill 一起安装。

## 快速调用

```text
$mm-article-orange-cat 给下面这篇文章做正文配图。每张只解释一个机制，橘猫必须参与关键动作。
```

也可以让上游自动选择：

```text
$mm-article-illustration 分析这篇文章并自动选择最合适的正文配图风格 Skill。
```

## 视觉基准

- 固定橘猫：黑针织帽、圆黑墨镜、黑高领
- 白底 / 暖白底
- 大量留白
- 细黑线稿
- 一图一个认知锚点
- 橙色 = 流程
- 蓝色 = 操作 / 解释
- 红色 = 风险
- 先解释清楚，再加一点冷幽默
