# Visual Assets

当前已归档两张经过确认的视觉锚点：

```text
assets/
├── preview.png
└── examples/
    └── example-red.png
```

## preview.png

默认主视觉锚点。

用途：锁定“手绘干货风”的核心观感：

- 标题是第一视觉中心
- 强关键词用主题色强调
- 一个真实业务对象承担主题落地
- 橘猫参与解释，但不压过标题
- 少量流程 / 图标 / 批注作为辅助
- 横版约 2.5:1

这张样本主要代表蓝白科技 / Coding 题材，不代表固定配色。

## examples/example-red.png

第二视觉锚点。

用途：证明同一视觉语言可以切换到红黑暖白体系，同时保持：

- 超强标题
- 产品 / UI 主对象
- 手绘橘猫 IP
- 粗笔刷与编辑感
- 少量信息图辅助

## Usage Rule

视觉样本优先级高于抽象文字描述，但**样本不是模板**。

生成时应学习它们的共同视觉 DNA，而不是机械复制：

- 不固定颜色
- 不固定“标题左 + 产品中 + 猫右”
- 不固定橘猫姿势
- 不固定产品位置

若样本中的具体构图与 `references/composition-patterns.md`、`color-system.md`、`ip-system.md` 的动态轮换规则冲突，以“保持品牌 DNA、避免重复模板”为目标重新组合。
