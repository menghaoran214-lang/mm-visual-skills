# Dynamic Color System

配色不属于固定风格身份，必须服从文章主题。

每张图建议：

- 1 个主色
- 黑 / 白 / 灰作为结构色
- 最多 1 个辅助强调色

## Theme Mapping

### AI / Coding / 部署
蓝、青蓝、深蓝、紫蓝。

### Web3 / Crypto / Agent
紫、深蓝、电光蓝、荧光绿。

### 赚钱 / 增长 / 项目实测
墨绿、亮绿、金黄、橙。

### 风险 / 踩坑 / 翻车
红、橙、黄、黑。

### 研究 / 深度分析
藏蓝、灰、酒红、暗金。

### 自媒体 / 内容 / 教程
浅绿、橙、红、奶油白，按平台与主题调整。

## Anti-fatigue Rule

不要因为“手绘干货风”就默认：
- 黄 + 蓝 + 黑
- 红 + 黑 + 白

如果最近两张主色接近，下一张主动换色域。

## Contrast

主色负责：
- 关键词
- 箭头
- 少量标记
- 局部背景或业务对象强调

不要让主色淹没整张图，除非文章本身需要强烈暗色/亮色海报感。
