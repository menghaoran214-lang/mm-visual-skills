# Reference Analysis

本 Skill 的视觉总结来自一组知识型标题封面参考。

这些参考图虽然颜色、题材和构图不同，但共同规律非常稳定：

## 不是固定模板

有的黑黄高对比，有的红黑白，有的极简黑白，有的绿红对比。

人物也可能：
- 在右侧大面积出现
- 在左侧作为主讲人
- 只是辅助角色

因此，**颜色和人物站位都不是风格本身。**

## 真正稳定的视觉 DNA

1. 大标题决定第一眼。
2. 标题通常同时存在“普通词 + 强调词”。
3. 一张封面只围绕一个核心议题。
4. 中间通常有一个真实对象帮助落地：手机、App、聊天界面、产品 UI、平台对比。
5. 手绘人物承担情绪与品牌识别。
6. 少量图标 / 流程承担“干货证明”。
7. 笔刷、箭头、网点、划线制造人工编辑感。
8. 整体是“编辑封面”，不是“把整篇文章做成图”。

## 关键判断

如果生成结果越来越像：
- 工程蓝图
- 复杂工作台
- 满屏服务器
- 多卡片 Dashboard
- 场景插画

即使画得漂亮，也说明偏离参考风格。

正确方向应回到：

> **标题海报为主，插画和信息图为辅。**
