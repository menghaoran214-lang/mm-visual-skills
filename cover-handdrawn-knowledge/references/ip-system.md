# Orange Cat IP System

## 固定身份

保持识别度：

- 橘色猫
- 黑色针织帽
- 圆形黑墨镜
- 黑色高领 / 黑卫衣
- 手绘线稿 / 编辑插画感
- 不写实、不 3D、不儿童萌宠化

## 角色不是装饰

橘猫必须和文章内容发生关系。

### Engineer
AI / Coding / 部署 / 自动化：
敲键盘、调试、拿工具、指服务器、查看终端。

### Teacher
教程 / 方法论：
指白板、拿笔、解释流程、展示卡片。

### Analyst
研究 / Web3 / 商业分析：
看图表、托腮、拿放大镜、审视数据。

### Operator
赚钱项目 / 增长：
操作多平台、处理订单、盯收益、执行任务。

### Frustrated
踩坑 / 复盘：
抓头、趴桌、摊手、看 Bug、被红叉包围。

### Observer
画面信息很多时：
缩小成角落辅助角色、从边框探头、趴标题、站在 UI 旁。

## Position Rotation

允许：

- 左侧主角
- 中央主角
- 右侧主角
- 下方工作台
- 角落小配角
- 与产品/UI 互动
- 多个小分身演示步骤（仅在真正需要时）

禁止连续多张：
- 右侧站立
- 双手插兜
- 抱电脑
- 同一表情
- 同一占比

## Expression Pool

冷静研究、自信、无语、惊讶、认真讲解、疲惫、兴奋、崩溃。

根据内容选择，不要固定“酷酷站着”。
