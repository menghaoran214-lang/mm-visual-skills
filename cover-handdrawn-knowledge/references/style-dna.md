# Style DNA · 手绘干货风

## 一句话定义

这是一种**标题海报为主、插画与信息图为辅**的知识型文章封面。

不是普通漫画，不是复杂信息图，不是 SaaS 科技海报，也不是课程宣传页。

## 共同 DNA

参考图真正稳定的共同点：

1. **超强标题**：占据最大视觉权重，通常 2–4 行。
2. **强关键词强调**：主色只砸在最关键的词上。
3. **手绘角色**：黑色线稿、速写、马克笔或漫画感。
4. **真实业务对象**：手机、软件界面、平台、产品、交易界面、图表等。
5. **少量信息图**：流程、图标、箭头、4 个以内的卖点。
6. **粗笔刷 / 手写批注**：制造“划重点”的干货感。
7. **高对比编辑排版**：信息多，但层级明确。

## Visual Weight

默认视觉权重：

标题 45–60%
→ 主业务对象 20–30%
→ IP 15–30%
→ 辅助信息 10–20%

比例可变，但标题必须第一。

## Typography

- 中文标题使用超粗黑体 / 海报字重
- 关键词允许换色、放大、下划线或轻微倾斜
- 一次最多使用 2 种强调手段
- 副标题更短、更像结论
- 避免大段正文
- 小字只承担说明，不承担核心信息

## Texture

允许：

- 手绘墨线
- 铅笔/马克笔纹理
- 粗笔刷
- 半色调网点
- 纸张颗粒
- 少量涂鸦箭头
- 少量撕纸/便签感

原则：

> 质感是辅助，信息可读性是主体。
