# QA Checklist

- [ ] 第一眼是否先看到标题？
- [ ] 3 秒内是否能理解文章主题？
- [ ] 主标题是否压缩为 2–4 行，而不是全文标题照搬？
- [ ] 核心关键词是否只强调 1–3 个？
- [ ] 是否只有一个主要业务对象？
- [ ] 辅助信息是否控制在 3–5 个？
- [ ] 橘猫是否保持固定身份？
- [ ] 橘猫是否参与表达，而不是纯装饰？
- [ ] 橘猫姿势、位置、表情是否与最近封面有变化？
- [ ] 配色是否根据主题选择，而非机械复用？
- [ ] 背景材质是否服务主题且不抢标题？
- [ ] 是否保持手绘线稿、笔刷、编辑设计的共同 DNA？
- [ ] 是否避免完整信息图 / Dashboard / PPT 化？
- [ ] 是否避免“复杂场景插画压过标题”？
- [ ] 横版比例是否约 2.5:1，或符合用户指定平台？
- [ ] 即使去掉小字，标题 + 主视觉是否仍能表达主题？

若有 3 项以上不通过，重新设计。
