# Negative Rules

以下情况视为明显跑偏：

- 标题不是第一视觉中心
- 变成复杂场景插画，人物和背景抢过标题
- 变成完整信息图 / Dashboard / PPT
- 一张图塞入整篇文章
- 超过 6 个辅助信息模块
- 默认每张都是“标题左 + 手机中 + 猫右”
- 默认每张都是黄蓝黑或红黑白
- 橘猫每次都站右侧、同一姿势、同一表情
- IP 巨大但与文章无关
- 没有真实业务对象却堆大量抽象装饰
- 大面积蓝紫渐变 SaaS 风
- 赛博朋克城市 / 电影场景 / 复杂光效
- 3D 萌宠、写实猫、儿童卡通
- 中文小字过多导致不可读
- 装饰箭头、网点、笔刷比内容更抢眼
- 多个产品/UI 同时争夺主视觉
- 为了“干货感”把画面塞满

## Hard Fail

出现以下任一项直接重做：

1. 第一眼先看到猫/场景而不是标题
2. 3 秒内说不出文章主题
3. 与上一张几乎同构图、同颜色、同姿势
4. 画面像复杂信息图而不像标题封面
5. 橘猫固定身份明显丢失
